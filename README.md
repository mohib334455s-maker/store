# Northlane Outfitters

English outdoor e-commerce store for COMP101 Project 1.

## Run

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000)

## Features

- 10 products imported from CSV
- Online product images
- Cart and checkout
- Inventory tracking and Out of Stock
- Order fulfillment with tracking number
- Mobile-friendly storefront
- Admin dashboard at `/login`
- Academic report at `/report`
- Presentation at `/presentation`
